# Завершення проєкту — що лишилось зробити

Код готовий і перевірений. Лишилось довезти його на сервер: **частина
змін ще не розгорнута**. Нижче — чотири кроки й перевірка.

---

## Крок 1. Копія бази (30 секунд)

Адмінка → внизу **«Зробити копію бази»** → **«Ні, тільки на сервері»**.

Робиться до оновлення, а не після. Якщо щось піде не так, буде куди
повернутися.

## Крок 2. Commit і push

Усе, що я віддавав, уже лежить у Вашій теці — звірив побайтово, розбіжностей
немає. Лишається звичне: stage → commit → push.

Коротко в описі коміту: `три статуси, масові дії, друк без дат, вхід учнів`.

## Крок 3. Розгортання

```bash
ssh root@159.69.87.168
/opt/deploy.sh
```

Ручних кроків цього разу немає: `Caddyfile` Ви вже оновили минулого разу,
`openpyxl` теж уже стоїть. Скрипт сам підтягне зміни, перезапустить службу
й перевірить, що вона відповідає.

**У журналі варто побачити** рядок про переведення старих статусів — якщо
в базі були «підтверджена» чи «відмова», вони переїдуть у «нову» й «архів»
відповідно:

```bash
journalctl -u beregynia -n 30 --no-pager | grep -i статус
```

## Крок 4. Перевірка живого сайту — шість пунктів

Займе хвилини три. Якщо всі шість у порядку — проєкт закритий.

1. **children.pp.ua** відкривається, у шапці дві кнопки: «Увійти» й
   «Записатися».
2. **Анкета**: обрати 4 клас — розкривається блок ГПД; обрати 11 —
   розкривається НМТ із предметами, і позначку з обов'язкових **можна
   зняти**.
3. **Адмінка** (`children.pp.ua/enter.html`): у фільтрі статусів рівно три —
   «нова», «зарахована», «архів». Угорі більше немає посилання «CSV».
4. **Пошук**: набрати прізвище малими літерами — знаходить.
5. **Друк**: позначити двох учнів одного напряму → «Додати до списку» →
   «Друк: прізвища й дати». Поставити галочку **«без дат»** — колонки
   порожні. Спробувати додати учня іншого напряму — має зʼявитися
   пояснення, що списки друкуються окремо.
6. **Вхід учня**: позначити одного учня → «Видати пароль» → відкрити
   `children.pp.ua/uchen.html` в іншому браузері й увійти. Має відкритися
   кабінет.

Якщо десь бачите стару сторінку — це кеш браузера, не сервер. Ctrl+F5.

## Що змінилося з часу останнього розгортання

* Три статуси замість пʼяти, старі переїжджають самі
* Кнопки «Зарахувати» і «В архів» для позначених
* Пошук по прізвищу без урахування регістру (кирилиця)
* Повні списки на друк — без дат: у ГПД дитина й дорослі при ній,
  у НМТ телефон, школа, предмети, батьки
* Галочка «без дат» для аркуша відвідування
* Один аркуш — один напрям; змішати неможливо
* Копія бази: спершу на сервер, пошта — за вибором; зберігається 10 копій
* Прибрано експорт CSV і номер заявки з екрана й листа батькам
* Обовʼязкові предмети НМТ можна зняти
* Анкета переживає видалення будь-якого блоку з розмітки

## Перевірено перед здачею

* Python і JS усіх сторінок компілюються без помилок
* Жодного битого внутрішнього посилання
* Усі 13 маршрутів адмінки, кабінет і три перевірки доступу — 200/302 як
  належить; учня не пускає ні в `/admin`, ні в картку дитини
* Обидві гілки анкети проходять до кінця, заявки лягають у базу
* Міграція старих статусів і старої структури бази — на копії живої бази
* Друк у PDF: обидва формати, по одній сторінці, нічого не обрізає
* Копія Вашої теки збігається з тим, що я віддавав, побайтово
